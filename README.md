# 犬山ユースプラットフォーム

犬山市の地域課題と大学生をつなぐマッチングプラットフォームの、動作するプロトタイプです。

**デモを開く → https://hikarizuoye197-tech.github.io/inuyamaplatform/**

## これは何か

犬山市では、犬山祭のわらじの作り手、犬山城の案内スタッフ、祭り道具の手入れ、放課後児童クラブなど、
各所で担い手不足が起きています。一方で大学生の側には「地域のために何かしたい」「経験を試したい」
という意欲がありながら、参加する入口が見えにくいという状況があります。

この二つをつなぐ仕組みとして、地域の「困った」を投稿し、学生が関わりの深さを選んで応募できる
プラットフォームを設計し、実際に触れるデモとして実装しました。

## 特徴

**関わりの深さを4段階に分ける** — 1日で終わる Lv.1「ちょい助け」から、行政インターンや政策提案を含む
Lv.4「まちづくり」まで。最初の一歩の敷居を下げつつ、本格的な挑戦まで同じ場所で受けとめます。

**双方向** — 地域から困りごとを投稿できるだけでなく、学生からも「犬山で○○したい」と提案できます。

**参加が記録として残る** — 活動履歴は経験証明として書き出せ、謝礼は市内で使える商品券として
地域内で循環します。

## 触れる機能

学生モード（画面右上で切り替え）

- 困りごとを探す — レベル・分野・キーワードでの絞り込み、並べ替え
- 案件の詳細 — カードをクリックすると詳細パネルが開き、応募すると募集人数と商品券残高が更新される
- やりたいことを出す — 学生からの企画提案の投稿と、共感の表明
- 活動を見る — 過去の活動の記録と成果
- マイページ — 参加履歴、到達レベル、商品券残高、経験証明

市民・企業・行政モード

- 困りごとを投稿 — 送信すると一覧に新着として反映される
- 応募状況 — 応募してきた学生の確認と承認
- 学生からの提案 — 受け手として名乗り出る

## 技術的なこと

HTML・CSS・JavaScript のみの単一ファイル（`index.html`）です。ビルド不要、フレームワークなし、
外部依存は Google Fonts の書体だけです。ファイルをブラウザで開けばそのまま動きます。

状態は `state` オブジェクトに集約し、変更後に `render()` で画面全体を描き直す一方向の流れで
組んでいます。案件データは `cases` 配列に定義してあるので、内容の追加や修正はそこだけで済みます。

## 注意

掲載している案件、活動実績、数値、人名はすべてサンプルです。実在の団体による募集ではありません。
